# ROAD i18n and UTF-8 Guide

ROAD uses UTF-8 for source, JSON, Markdown, and script files.

## Rules

- Keep Go code user-facing text behind locale keys.
- Keep the English catalog as the source template: `locales/en.json`.
- Add translations by copying `locales/en.json` to `locales/<lang>.json`.
- Keep keys stable once published.
- Use dotted lower-case keys, for example `menu.choose_mode` or `client.starting`.
- Use `%s`, `%d`, `%v`, and `%w` formatting exactly like Go `fmt`.
- If a key is missing in the selected language, ROAD falls back to English.
- If the key is missing from English too, ROAD returns the key name and records it in the missing-key report.

## Current Languages

- `en`: primary template and fallback.
- `tr`: first translation file.

## Runtime Loading

`cmd/road`, `cmd/plugin-studio`, `cmd/server`, and `cmd/client` read`r`n`configs/app.json` for command-level user-facing text:

```json
{
  "language": "en"
}
```

Supported values currently normalize to:

- `en`
- `tr`

Locale files are loaded from `locales/` next to the running binary. Source-tree runs also work because ROAD resolves relative paths from the current working directory and executable location.

## Adding a New String

1. Add a new key to `locales/en.json`.
2. Add the translated value to `locales/tr.json` if available.
3. Use the key from Go code with `msg("key.name")` in `cmd/road`, `sm("key.name")` in `cmd/plugin-studio`, or a translator loaded through `internal/cli` for simple command binaries.
4. If formatting is needed, use `fmt.Sprintf(msg("key.name"), value)` or `fmt.Errorf(msg("key.name"), err)`.
5. Run `go test ./...`.

## Encoding Checks

Recommended local checks:

```powershell
go test ./...
Get-Content .\locales\tr.json -Encoding UTF8 | ConvertFrom-Json | Out-Null
```

Windows console behavior:

- `cmd/road` calls `enableConsoleUTF8()` on Windows.
- Windows Terminal and PowerShell 7 generally handle UTF-8 correctly.
- Windows PowerShell 5 and classic `cmd.exe` may still depend on console font and code page behavior.
- On 2026-05-11, Windows PowerShell 5.1 and `cmd.exe` were smoke-tested with Turkish `configs/app.json` output successfully.
- PowerShell 7 and Windows Terminal still need a machine/session where `pwsh.exe` and `WT_SESSION` are available.

## Release Packaging

Build scripts copy `locales/` into Windows and Linux output folders. Release packages must include:

- binaries
- `configs/`
- `plugins/`
- `locales/`
- `README.md`
- `CHANGELOG.md`
- `VERSION.txt`
